# Issam Terminal Portfolio

Interactive terminal-style portfolio built with Vue 3 + Vite.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Commands

- `help`
- `ls`
- `cd about`
- `cd projects`
- `cd skills`
- `cd contact`
- `whoami`
- `github`
- `clear`

## Build

```bash
npm run build
```

The production files are generated in `dist/`.
